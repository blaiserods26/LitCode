# 13: Data Structure Visualizer (TreeNode & ListNode)

**What to build:** Automatic visual rendering of LeetCode serialized test inputs (such as `[3,9,20,null,null,15,7]` or `[1,2,3,4,5]`) as interactive SVG diagrams in the Webview companion tab, plus built-in `ListNode`/`TreeNode` helper definitions injected into local starter stubs.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Parser for serialized array representations of binary trees (level-order traversal with nulls)
- [ ] Parser for serialized array representations of singly linked lists
- [ ] SVG tree generator calculating hierarchical node coordinates and branch lines
- [ ] SVG linked list chain generator with pointer arrows
- [ ] Interactive toggle button in Webview test cases to view visual representation
- [ ] Injection of standard `ListNode` and `TreeNode` helper classes into Python and TypeScript solution templates
