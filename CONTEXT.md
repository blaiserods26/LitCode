# LeetCode Practice Companion

A VS Code extension designed for frictionless, local-first algorithmic problem solving, curated curriculum tracking, and Socratic AI coaching.

## Language

**Problem**:
A LeetCode coding challenge containing a title, slug, statement markdown, examples, constraints, hints, and default code stubs.
_Avoid_: Question, puzzle, task

**Daily Challenge**:
The official LeetCode problem of the day scheduled for the current UTC date.
_Avoid_: Daily problem, problem of the day, daily task

**Study Plan**:
A curated sequence of problems grouped by category or difficulty (e.g., Striver's SDE Sheet, NeetCode 150, Blind 75, or custom imported plans).
_Avoid_: Sheet, roadmap, playlist

**Solution Storage**:
The dedicated global system-local filesystem directory where the user's attempted problem solution files are persisted outside of the active editor workspace.
_Avoid_: Project cache, temp folder, workspace files

**Bookmark**:
A user-flagged problem saved locally in VS Code storage for fast review and revisit.
_Avoid_: Favorite, starred question, saved problem

**Local Test Runner**:
The in-editor execution harness that wraps the user's solution and runs it against sample or custom test cases using local runtimes.
_Avoid_: Executor, interpreter, compiler

**Remote Submission**:
An optional authenticated dispatch of the user's code to LeetCode's backend to register official acceptance and streak updates.
_Avoid_: LeetCode upload, official run

**Socratic Coach**:
The AI helper configured to give hints, ask guiding complexity/invariant questions, and nudge without ever outputting executable solution code.
_Avoid_: AI solver, bot, copilot
